For creative technologists and builders

An open language. Not a locked visual effect.

MORPHA defines principles independent of a particular rendering stack. Its browser reference uses JavaScript, Three.js and shaders while the protocol itself stays implementation-agnostic.

01 / SPECIFICATION

Protocol before platform

Study the open draft defining glyph families, grammar, silence, overlap and continuous form.

02 / TESTABILITY

Explicit invariants

The reference project includes automated unit and partial protocol-conformance tests, plus browser smoke checks.

03 / REFERENCE STACK

Inspectable implementation

Vite, Three.js, GLSL and a deterministic core provide concrete code to inspect and adapt.

Design advantage

Build distinct implementations.

The protocol describes structural behavior instead of prescribing a single visual style. That makes it relevant to web graphics, spatial computing, music software and experimental interfaces.

Current limitation: a separately packaged public SDK and complete interoperability suite are future work. Do not assume that a stable production API exists.

Governance

Extensions without enclosure.

The protocol invites independent implementations and extension documents. The specification's stated licensing model is CC0; check individual repository assets and code licensing separately before redistribution.
